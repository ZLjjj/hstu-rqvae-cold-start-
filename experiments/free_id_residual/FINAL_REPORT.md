# 内容基础表示 + 暖物品 Free-ID Residual：最终实验报告

## 1. 实验结论

本轮实验已完整结束。15 组 beta 扫描与 12 组三随机种子正式实验均自然退出，`suite.exit` 为 `exit_code=0`。完整测试为 **105 passed**，正式实验的 12 份协议审计全部通过。

主要结论如下：

- **B1（对称 Free-ID，beta=1.0）取得最佳 Cold Top-K**：Cold HR@100 为 **0.3694±0.0377**，Cold NDCG@100 为 **0.0839±0.0091**，相对新协议 B0 分别提高 **123.7%** 和 **95.2%**。
- **B3（对称 Free-ID + 0.2 dropout，beta=1.0）取得最佳 Warm 和 Overall 综合表现**：Overall NDCG@100 为 **0.1888±0.0030**，Warm NDCG@100 为 **0.2003±0.0032**，相对 B0 分别提高 **54.2%** 和 **53.8%**。
- B2（仅候选侧 Free-ID，beta=0.5）没有复现此前 H0-C1 的异常高 Cold 指标；其 Cold NDCG@100 只比 B0 高 **11.6%**，显著低于 B1/B3。
- residual 模型的 Cold-vs-All 都提高，但 Cold-vs-Cold NDCG@100 均低于 B0。因此主要改善来自**暖候选重排与暖冷分数校准**，不能解释为冷物品内容语义表示本身变好。
- B1 的 Cold 指标提升最大，但三种子波动也最大；B3 的 Overall/Warm 最稳定，是更均衡的统一模型。

## 2. 模型与实验组

内容基础表示保持为 `e_base = W0 z + b`，输出维度 50。embedding 模块内部不提前归一化，历史表示以未归一化形式进入 HSTU；用户向量和候选表示只在最终点积前沿用原有 L2Norm。

只为训练正曝光过的暖物品建立 50 维、全零初始化的 Free-ID residual：

`e_i = e_i_base + beta * r_i_ID`（暖物品），`e_i = e_i_base`（严格冷物品）。

| 组别 | 历史侧 | 候选侧 | Dropout | 验证集选择的 beta |
|---|---|---|---:|---:|
| B0 | content | content | 0 | 0 |
| B1 | content + ID | content + ID | 0 | 1.0 |
| B2 | content | content + ID | 0 | 0.5 |
| B3 | content + ID | content + ID | 0.2 | 1.0 |

B1/B2/B3 的残差表包含 3333 个训练正曝光暖物品，共 166650 个残差参数；冷物品没有索引。B0 可训练参数量为 46400，B1/B2/B3 为 213050。

## 8. 十个研究问题的回答

1. **Free-ID 是否超过新协议 B0？** 是。三种 residual 组在 Overall AUC/HR@100/NDCG@100、Warm 指标以及 Cold-vs-All AUC/HR@100/NDCG@100 上均超过 B0。B1 的 Cold NDCG@100 提升 95.2%，B3 的 Overall NDCG@100 提升 54.2%。
2. **B1 和 B2 哪个 Cold Top-K 更好？** B1 明显更好：HR@100 0.3694 对 0.2183，NDCG@100 0.0839 对 0.0480。
3. **B2 是否复现此前 H0-C1 的高 Cold？** 没有。训练/推理候选路径一致后，B2 只取得有限 Cold 提升，且远低于 B1/B3。
4. **Cold 改善来自内容表示还是暖候选重排？** 主要来自暖候选重排和暖冷校准。B1 的 Cold-vs-All NDCG@100 从 0.0430 升至 0.0839，但 Cold-vs-Cold 从 0.1674 降至 0.1482。
5. **Cold-vs-All 与 Cold-vs-Cold 是否同步？** 不同步。B1/B2/B3 的 Cold-vs-All NDCG 均上升，Cold-vs-Cold NDCG 均下降；因此不能声称冷物品语义表示变好。
6. **是否出现 AUC 上升但 HR/NDCG 下降？** 主 Cold-vs-All 结果没有；但 Cold-vs-Cold 出现局部不一致。例如 B1 AUC 从 0.6870 升到 0.6954，而 NDCG@100 从 0.1674 降到 0.1482；B3 AUC升至 0.7037，但 HR@100/NDCG@100仍低于 B0。
7. **ID residual 是否压制内容分支？** 没有 base norm 坍塌的直接证据；但 B1/B2 scaled ratio 约为 0.94/1.09，且冷内部排序退化，说明存在较强 ID 依赖。B3 dropout 把 ratio 压至约 0.50，并获得最佳 Overall/Warm。
8. **beta 如何影响 ratio 和排序？** 未缩放 residual 会随 beta 增大而收缩，scaled ratio 整体接近常数量级；排序并不单调。B1 选择 1.0，B2 在 0.5 达峰后于 1.0 回落，B3 在 0.5–1.0 平台化。
9. **ID Dropout 是否改善 Cold 且保留 Warm/Overall？** 相对 B1，B3 没有改善 Cold（NDCG@100 0.0720 对 0.0839），但显著改善 Warm/Overall（Warm NDCG@100 0.2003 对 0.1716；Overall 0.1888 对 0.1637），并降低方差。它是整体稳健性方案，不是 Cold 最优方案。
10. **多随机种子是否稳定？** Overall/Warm 较稳定，尤其 B3；Cold 样本仅 545，波动更明显。B1 Cold NDCG@100 的标准差 0.0091（约均值 10.9%），B3 为 0.0041（约 5.7%）。结论方向在三个种子上保持一致，但 Cold 精确数值仍应报告置信限制。

## 10. 最终建议

- 若首要目标是**严格 Cold Top-K**，选择 B1（symmetric，beta=1.0）。
- 若需要**Warm/Overall 最优且跨种子更稳定**，选择 B3（symmetric，beta=1.0，dropout=0.2）。
- 不推荐 B2 作为统一最优模型；它证明仅候选侧 residual 的收益主要是候选校准，不能复现高 Cold 语义排序。
- 后续可在多个冷集合 seed 上复验 B1/B3，并针对 B1 增加约束以保持 Cold-vs-Cold NDCG；本轮未事后追加 dropout 网格，避免扩大预注册搜索和测试集回选风险。
